# Okula

Учебный проект на Ruby on Rails. Личный кабинет сервиса Okula, который следит за сайтами и лендингами малого и среднего бизнеса и помогает им попадать в ответы ИИ-поисковиков (Яндекс Нейро, Алиса, AI Overviews, ChatGPT, Perplexity).

## Что есть

- регистрация: пароль генерируется и приходит на почту, дальше онбординг с подключением сайта
- дашборд: баллы оптимизации, советы, график упоминаний в ответах нейросетей, продвигаемые страницы
- задачи: доска «Запланировано / В работе / Выполнено», задачу можно перенести в следующую колонку
- советы: статьи с категориями, поиском и страницей статьи
- помощник: вопрос ИИ-помощнику, ответ и кнопка «Добавить задачу»
- настройки: профиль, тариф, код подключения сайта, подключённые сайты
- админка `/admin`: создание, редактирование и удаление советов и категорий
- все страницы, которых пока нет в макете, открывают страницу «в разработке» (404)
- мобильная версия

## Стек

- Ruby 4.0.6
- Rails 8.1
- SQLite
- Devise
- Stimulus

## Запуск

```shell
bundle install
rails db:drop db:migrate db:seed
rails s
```

На Windows `db:drop` может не удалить базу, тогда удалить `storage/development.sqlite3` руками и запустить `rails db:migrate db:seed`.

## Письма

Без настроек письмо с паролем сохраняется в папку `tmp/mails`. Чтобы письма уходили на настоящую почту через Яндекс, перед запуском задайте переменные:

```shell
export SMTP_USERNAME=почта@yandex.ru
export SMTP_PASSWORD=пароль_приложения
rails s
```

Пароль приложения создаётся в настройках Яндекс ID → Безопасность → Пароли приложений.
